[Flue](https://flueframework.com/) is a TypeScript harness framework for building agents and agent-backed workflows. On Cloudflare, Flue builds your project into a Worker and uses the Agents SDK runtime for Durable Object-backed agent instances.

## Start with an agent prompt

Copy this prompt and give it to Claude Code, Codex, Cursor, OpenCode, or another coding agent. It will read Flue's guide and create a Cloudflare-targeted project with you.

<CopyPromptButton
	prompt={fluePrompt}
	showAgentIcons={false}
	variant="primary"
/>

The agent will help you choose:

- The agent or workflow you want to build
- The Flue source layout for your project
- The model provider and model specifier

When the generated project is ready, run it locally with Flue's Cloudflare target:

<PackageManagers type="exec" pkg="flue" args="dev --target cloudflare" />

Build the Cloudflare Worker artifact:

<PackageManagers type="exec" pkg="flue" args="build --target cloudflare" />

Deploy with `wrangler`:

<PackageManagers type="exec" pkg="wrangler" args="deploy" />

## What runs where

| Question                         | Answer                                                                                                                               |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Where does the agent run?        | In an Agents SDK Durable Object. Flue generates the Durable Object class and binding for each Cloudflare-targeted agent or workflow. |
| Where is session history stored? | In Durable Object SQLite. This preserves conversation state, but not files in the default virtual sandbox.                           |
| Where does a container run?      | In [Cloudflare Containers](/containers/) through [Sandbox](/agents/tools/sandbox/). Use this when the agent needs a Linux container. |

## How Flue uses the Agents SDK

| Agents SDK part                                                                                                    | How Flue uses it                                                                                   |
| ------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| [`Agent` class](/agents/runtime/lifecycle/agent-class/)                                                            | Gives each generated Flue agent or workflow a durable identity and lifecycle on Cloudflare Workers |
| [Durable Object SQLite](/agents/runtime/agents-api/#sql-api)                                                       | Stores each Flue agent session in the agent's SQLite database                                      |
| [Durable execution fibers](/agents/runtime/execution/durable-execution/)                                           | Provides a recovery boundary for accepted work when a Durable Object is interrupted                |
| [Scheduled tasks and alarms](/agents/runtime/execution/schedule-tasks/)                                            | Lets Flue coordinate runtime wakes, scheduled work, and background activity                        |
| [State](/agents/runtime/lifecycle/state/), [queues](/agents/runtime/execution/queue-tasks/), and lifecycle methods | Exposes additional Agents SDK functionality you can use from a Flue agent                          |

Use Flue's Cloudflare extension point when you need native Agents SDK hooks. For example, add a recurring scheduled method to the generated `assistant` agent:

<TypeScriptExample filename=".flue/agents/assistant.ts">

```ts
import { createAgent, type AgentRouteHandler } from "@flue/runtime";
import { extend } from "@flue/runtime/cloudflare";

export const description = "Answers Cloudflare Workers questions.";

export const route: AgentRouteHandler = async (_c, next) => next();

export default createAgent(() => ({
	model: "cloudflare/@cf/moonshotai/kimi-k2.6",
	instructions:
		"Answer Cloudflare Workers questions clearly. State uncertainty when you are not sure.",
}));

export const cloudflare = extend({
	base: (Base) =>
		class extends Base {
			async onStart() {
				await this.scheduleEvery(60, "heartbeat");
			}

			async heartbeat() {
				this.setState({ ...this.state, lastHeartbeatAt: Date.now() });
			}
		},
});
```

</TypeScriptExample>
