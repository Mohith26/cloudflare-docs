A harness is the loop that runs an agent. It decides how the agent receives a message, calls a model, selects tools, handles tool results, streams output, persists state, and decides whether to continue or stop.

You can build this loop yourself with the [Agents SDK runtime](/agents/runtime/agents-api/), or use an opinionated harness like [Project Think](/agents/harnesses/think/).

## Harnesses and runtime

Harnesses sit on top of the Agents SDK runtime:

- **The runtime** provides durable infrastructure: the `Agent` class, state, sessions, routing, WebSockets, scheduling, fibers, and observability.
- **The harness** provides agent behavior: the model call, prompt construction, tool selection, stream handling, memory strategy, and extension points.

Use the runtime directly when you need full control over every part of the loop. Use a harness when you want common agent behavior packaged into a reusable base class.
