[Pi](https://pi.dev/docs/latest) is a minimal terminal coding harness. On Cloudflare, you can embed Pi's model-facing loop in an Agents SDK Durable Object when you want Pi to control the agent behavior and Cloudflare to provide the durable runtime.

Use this pattern when you want a custom Worker API around Pi instead of a generated harness application. The Worker receives requests, routes them to an Agents SDK `Agent`, and that `Agent` runs a Pi turn inside a durable fiber.

## Start with an agent prompt

Copy this prompt and give it to Claude Code, Codex, Cursor, OpenCode, or another coding agent. It will read Pi's SDK docs and the complete [Pi on Cloudflare example](https://github.com/irvinebroque/pi-on-cloudflare) and create a Cloudflare-targeted project with you.

- The Worker API or UI you want around Pi
- The model and AI Gateway configuration
- Whether to expose a code execution tool
- The recovery behavior for interrupted turns

## How Pi uses the Agents SDK

| Agents SDK part                                                 | How Pi uses it                                                                                                      |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| [`Agent` class](/agents/runtime/lifecycle/agent-class/)         | Hosts the `PiAgent` Durable Object and gives the Pi loop access to `this.env`, `this.state`, `setState()`, and SQL |
| [`getAgentByName()`](/agents/runtime/communication/routing/)    | Routes custom Worker API requests to a stable agent instance, such as `"default"` or a user ID                     |
| [Durable Object SQLite](/agents/runtime/agents-api/#sql-api)    | Stores Agents SDK state and fiber metadata for the `PiAgent` class                                                  |
| [Durable execution fibers](/agents/runtime/execution/durable-execution/) | Runs a Pi turn as durable work with `runFiber()` and checkpoints recovery input with `stash()`              |
| [State](/agents/runtime/lifecycle/state/)                       | Stores small durable metadata, counters, and recovery evidence                                                      |

Use `startFiber()` instead of `runFiber()` when callers need durable acceptance, idempotency, cancellation, and later status inspection rather than a single request waiting for the turn result.

Pi does not include a built-in sandbox. If you expose tools that run code, route them through an isolation boundary such as [Dynamic Workers](/dynamic-workers/), [Sandbox](/agents/tools/sandbox/), [Containers](/containers/), or another sandbox appropriate for your application.
